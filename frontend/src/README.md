# Inventory System Frontend

React + Vite frontend for the Inventory System.

## Included

- Dashboard and existing inventory screens
- Inventory sessions, reports and attention items
- Branches with search, status filtering, CRUD and pagination
- Stores with search, branch/status filtering, CRUD and pagination
- Code-based sorting for branches and stores
- Arabic and English localization with RTL/LTR support
- Existing reusable layout, loading, empty, error and icon components
- API service layer for backend communication
- CSS Modules with responsive polished cards, tables and forms

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The frontend expects the API base URL configured in `services/api/apiConfig.js`.
